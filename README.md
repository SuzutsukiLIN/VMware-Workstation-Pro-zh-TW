# VMware Workstation Pro 26H1 繁體中文化研究紀錄

**適用 VMware Workstation Pro 26.0.1（build 25688693）｜繁體中文（台灣）｜ES 相容模式 v1.2**

> [!NOTE]
> 本專案是非官方的**語系相容性研究、中文化修正與實機測試紀錄**，不是 VMware / Broadcom 官方語言套件。
> 專案不包含 VMware 主程式，也不提供授權繞過功能。

## 研究成果

從舊版繁體中文語系開始，發現在 26H1 版本使用原有 `zh_TW` 目錄，雖然部分畫面顯示中文，新增虛擬機精靈的標題、選項等仍會退回英文。

經過字串與 Win32 對話框資源比對、PowerShell 載入檢查，以及原生西班牙文語系的對照測試，找到可行方式：

**保留 VMware 26.0.1 原生 `es` 語系 DLL 的資源識別碼與結構，把顯示內容改成繁體中文，並用 `vmware.exe --locale=es` 啟動。**

已在 Windows 實機確認：精靈歡迎頁、安裝系統、虛擬機命名與 TPM 加密設定等主要畫面可顯示中文；**v1.2 整合一鍵安裝及桌面捷徑**亦已獲實機測試回報 OK。

### 一鍵安裝的實際流程

已完成測試的 v1.2 **完整整合包**，設計為：

1. 先安裝 **VMware Workstation Pro 26.0.1** 並完全關閉程式。
2. 解壓縮已備妥語系資源的整合包，雙擊 `Install.cmd`。
3. 安裝器確認版本、備份原有檔案、安裝繁中語系並建立桌面捷徑。
4. 以 **「VMware Workstation Pro - 繁體中文」** 桌面捷徑直接啟動。

**不須編輯 `preferences.ini`，也不用自行建立啟動參數。**

> **本公開儲存庫目前保存研究與安裝器原始碼，不含 v1.2 完整整合包中的 VMware 衍生 DLL 與 `vmware.vmsg`。**

## 研究過程

1. **問題發現：** 將舊版繁中語系放到 26H1，部分文字退回英文。
2. **檔案比對：** 分析 `vmware.vmsg`、`vmappsdk`、`vmui` 的字串與資源。
3. **載入定位：** 確認 `.vmsg` 有載入、中文 DIALOG 資源存在，但某些畫面仍退回英文。
4. **原生 ES 對照：** 相同精靈在西班牙文模式可完整翻譯。
5. **相容模式：** 保留原生 ES 資源代碼與檔名後，繁中介面成功顯示。
6. **v1.1／v1.2：** 修正 TPM 標籤、字串長度與台灣繁中用語。
7. **一鍵安裝：** 加入版本檢查、備份、桌面捷徑與還原程式；安裝及捷徑功能已實機測試。

詳見 [研究紀錄與技術細節](docs/RESEARCH_LOG.md)。

# VMware Workstation Pro 繁體中文（台灣）｜ES 相容模式

> **非官方社群專案**；與 VMware / Broadcom 無隸屬關係。目前驗證平台：**Windows x64、VMware Workstation Pro 26.0.1（build 25688693）**。

## 專案要解決什麼？

VMware Workstation 26H1 已移除官方繁體中文語系。此專案利用 **26.0.1 原生 ES 語系載入機制**，在不修改 `vmware.exe` 的前提下，於本機安裝繁體中文資源，並自動建立桌面捷徑：

**VMware Workstation Pro - 繁體中文**

桌面捷徑直接啟動 `vmware.exe --locale=es`，不須手動編輯 `preferences.ini`。

## 一般使用者：未來預期的安裝方式

1. 先從 Broadcom 正式管道安裝 **VMware Workstation Pro 26.0.1**。
2. 從本專案 **Releases** 下載一鍵安裝程式。
3. 完全關閉 VMware，執行安裝程式；程式自動辨識版本、備份原始資源、使用本機原生 ES 檔案套用繁體中文修補。
4. 安裝完成後，直接從桌面 **「VMware Workstation Pro - 繁體中文」** 捷徑啟動。

**目標是一般使用者無須 VM17 ZIP、ES ZIP 或 Python。** 這是開發目標，而非目前已公開交付的功能。

要實現此功能，專案仍需取得可合法公開散布的翻譯資料／差異補丁，並完成乾淨 Windows 環境的安裝及還原測試。**「只散布二進位差異」不會自動消除原廠翻譯的著作權或授權限制。**

## 安裝器已實作的安全措施

- 僅支援經驗證的 26.0.1（build 25688693），拒絕其他版本。
- 嚴格比對原始、安裝後資源 SHA-256。
- 安裝前備份，安裝後驗證；不會直接修改虛擬機器檔案。
- 重複安裝不重複覆寫已通過檢查的 v1.2。
- 桌面捷徑透過 `--locale=es` 啟動，不修改 VMware 偏好設定。
- 無法辨識的檔案、無原始備份等情況均應停止，不直接強制覆蓋。

## 已知限制

- 目前只針對 26.0.1 版本測試，不能假設其他 VMware 版本相容。
- 部分動態版本名稱（例如 `Workstation 25H2 or later`）可能仍顯示英文。
- 其他設定頁面、不同 DPI 與解除安裝／回滾尚未全部完成實機驗收。
- 修改 DLL 會使其原廠數位簽章失效；不代表 Broadcom 官方支援。
- VMware 官方下載可能要求登入 Broadcom 帳號及接受下載條款。

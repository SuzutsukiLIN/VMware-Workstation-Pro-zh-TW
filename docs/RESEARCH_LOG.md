# VMware Workstation 26H1 繁體中文化研究紀錄

研究日期：2026-10-28  
目標版本：Windows x64 VMware Workstation Pro 26.0.1，build 25688693  
結論：**使用原生 ES 相容載入路徑，可以在已測試介面顯示繁體中文。**

## 原始問題

以舊版繁中 `zh_TW` 語系檔案直接加入新版本，部分介面已中文化，但新增虛擬機精靈中仍混雜英文：歡迎畫面、Typical / Custom、Install from、Virtual machine name、TPM 加密欄位等。

## 診斷流程與發現

| 階段 | 觀察 | 推論與限制 |
|---|---|---|
| `vmware.vmsg` 字串比對 | 新舊版本有字串識別碼差異 | 補齊字串是必要但非充分條件 |
| Win32 DIALOG 資源比對 | `vmappsdk` DLL 裡已有精靈選項中文翻譯 | 需要區分資源存在與執行時實際使用 |
| A～I 文字標記 | 部分標記出現、其他選項仍是英文 | `.vmsg` 的載入正常，不能解釋所有英文項目 |
| DLL 資源檢查 v2 | 四組相關 DIALOG 中文資源可讀取 | 不等於 VMware 已選用語系資源 |
| 執行階段映射 v3.1 | 偵測到主程式 `vmappsdk.dll`，未在該次掃描中偵測到 zh_TW DLL | 單次記憶體映射不足以證明 DLL 永遠不曾載入 |
| 原生西班牙文對照 | 同一精靈在原生 ES 模式顯示完整西班牙文 | 確認新版本精靈仍可載入本地化資源 |
| 26.0.1 ES 資源相容移植 | 將對話框文字改為繁體中文，保留原生 ES DLL 結構／編號 | 已測試畫面成功顯示中文 |

## 版本演進

### v1.0：ES 相容模式

不修改 `vmware.exe`。使用 26.0.1 原生 `es` 語系資源的命名與資源識別碼，將文字移植為台灣繁體中文，以：

```bat
vmware.exe --locale=es
```

啟動。實機已看到精靈主要文字轉成中文。

### v1.1：介面標籤改善

縮短 TPM 加密選項說明與「確認密碼」標籤，減少固定寬度控制項的斷行；調整部分簡體／中國用語為台灣用語。

### v1.2：文字長度與排版

針對「安裝作業系統」及歡迎頁的 `.vmsg` 說明文字縮短，保留動態參數。動態版本字樣如 `Workstation 25H2 or later` 不保證全部翻譯。

### 一鍵安裝整合

加入 `Install.cmd`、版本與 SHA-256 檢查、原始資源備份、語系資源替換、桌面繁中啟動捷徑與 `Uninstall.cmd`。已收到使用者 Windows 實機回報：整合安裝與桌面捷徑測試 OK。解除安裝及不同環境的完整相容性仍須進一步驗證。

## 目前保留的技術限制

- 僅驗證 VMware 26.0.1 build 25688693；不可無條件套用其他版本。
- 這是非官方中文化相容研究，不代表 Broadcom 支援。
- 資源文件的存在不等於所有程式功能已經完整繁中化。
- 自製 DLL 不具有效的原廠數位簽章。
- 本公開 GitHub 儲存庫不含 VMware 原廠或衍生 DLL/VMSG；已驗收的完整整合包與公開原始碼包是兩種不同成品。

## 後續
